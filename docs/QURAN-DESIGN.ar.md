# لماذا النص المحلي بدل صور المصحف؟

الاختيار المنفذ: JSON محلي للنص والمرجع وبيانات الجزء والصفحة، مع خط Amiri Quran. هذا يتيح البحث والنسخ وتحديد الآية والصوت المرتبط بها والملاحظات وتغيير الحجم وإمكانية القراءة دون إنترنت. حجم JSON الكامل نحو 2.59 MB، دون ملفات الصوت. يُقرأ بكود JSON مولّد وقت البناء لتقليل الانعكاس، ويُحمّل مرة واحدة وتُعرض الآيات بقائمة CollectionView افتراضية بدل إنشاء كامل القرآن كعناصر واجهة.

الصور مفيدة للمطابقة البصرية الحرفية لصفحات المصحف المطبوع، لكنها تحتاج بيانات إضافية لتحديد الآيات والبحث، وتزيد أحجام التنزيل. العرض النصي الحالي يستخدم أرقام صفحات المصحف في البيانات ولا يدّعي مطابقة مواضع السطور والزخرفة في المصحف المطبوع. يُمكن لاحقًا إضافة وضع مطبوع اختياري بعد توفير خط/بيانات تخطيط مرخصة ومراجعتها.

## المصدر والحفاظ على النص

- النص: https://tanzil.net/pub/download/index.php?quranType=uthmani&outType=txt-2&agree=true
- الترخيص: https://tanzil.net/docs/text_license — CC BY 3.0 مع شرط إبقاء النص حرفيًا وإظهار المصدر والرابط.
- الملف الأصلي وإشعار الحقوق مرفقان في Resources/Raw. يتضمن quran.json إشعار الحقوق نفسه.
- metadata للصفحات والأجزاء من https://api.alquran.cloud/v1/quran/quran-uthmani.
- ملف quran-provenance.json يتضمن بصمتي SHA-256 للمصدر وJSON.
- الاختبارات تقارن 6236 آية بالمصدر حرفًا بحرف. لا يغيّر البحث النص؛ يزيل التشكيل من نسخة فهرسة مشتقة من مصدر Tanzil simple-clean مستقل فقط.
- البسملة في أول آية للسور تُحفظ كما وردت من تنزيل؛ لم تجرِ إعادة تقسيم نص الآيات.

## المصادر المجانية

- خط Amiri Quran: https://github.com/google/fonts/tree/main/ofl/amiriquran — SIL OFL 1.1. الترخيص مرفق.
- الصوت والتفسير: https://alquran.cloud/api وhttps://alquran.cloud/terms-and-conditions — API مجاني بلا مفتاح. حقوق التسجيلات باقية لأصحابها. الخدمة الخارجية قد تتوقف أو تغير شروطها؛ النص المحلي لا يعتمد عليها.
- الأذكار: https://github.com/AbdelrahmanBayoumi/Azkar-App — MIT. الملف الأصلي 34 مدخلًا مع المراجع، ويضاف إليه 10 أذكار نوم/بعد الصلاة ذات مراجع داخل التطبيق.
- حساب الصلاة: https://github.com/stankovski/adhan-csharp — MIT؛ الحساب على الجهاز.
- مكونات .NET MAUI وCommunity Toolkit مفتوحة المصدر؛ لا توجد خدمة مدفوعة أو اشتراك أو حساب API مضاف.

التلاوة مخزنة كملفات MP3 مستقلة للآيات. التنزيل تسلسلي بحد أقصى طلب واحد مع إمكانية الإلغاء، والملف الجزئي لا يصبح ملفًا صالحًا إلا بعد إتمام الطلب. إعادة التنزيل تتجاوز الآيات المكتملة. حذف الملفات من الإعدادات ينتظر انتهاء/إلغاء أي عملية تنزيل.
